🎉 RECIPE BOOK SITE - ИНСТРУКЦИИ ПО УСТАНОВКЕ

Вот все файлы проекта готовы! Вот что нужно сделать:

═══════════════════════════════════════════════════════════════

1️⃣  СУPABASE SETUP (ОДИН РАЗ)

1. Открой https://supabase.com
2. Перейди в SQL Editor в твоём проекте
3. Скопируй содержимое recipe_book_schema.sql
4. Запусти (кнопка Run)
5. Затем перейди Settings → API и скопируй:
   - Project URL (полный адрес)
   - Anon Public Key

═══════════════════════════════════════════════════════════════

2️⃣  ОБНОВЛЕНИЕ КОНФИГА

1. Открой файл: js/config.js
2. Найди строки:
   URL: 'https://YOUR_PROJECT_ID.supabase.co',
   ANON_KEY: 'YOUR_ANON_KEY'

3. Замени на свои значения:
   URL: 'https://твойпроект.supabase.co',  
   ANON_KEY: 'eyJhbGc...' (твой ключ)

═══════════════════════════════════════════════════════════════

3️⃣  ЗАГРУЗКА НА GITHUB

Структура папок:
recipe-book-site/
├── index.html
├── book.html
├── admin.html
├── js/
│   ├── config.js (с твоими ключами)
│   └── db.js
└── README.md

1. Создай новый репозиторий на GitHub: recipe-book-site
2. Загрузи все файлы в папки как указано выше
3. Перейди в Settings → Pages
4. Выбери: Deploy from a branch
5. Branch: main, Folder: /
6. Твой сайт будет доступен: https://username.github.io/recipe-book-site/

═══════════════════════════════════════════════════════════════

4️⃣  ИСПОЛЬЗОВАНИЕ

Главная: index.html
  → Информация о сайте, ссылки

Книга: book.html  
  → Просмотр всех рецептов
  → Навигация стрелками

Админ: admin.html
  → Пароль: addnew
  → Добавление рецептов
