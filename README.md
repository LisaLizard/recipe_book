# 📖 Recipe Book Site

Интерактивная книга веган-рецептов с админ-панелью для добавления новых рецептов.

## 🚀 Быстрый старт

### 1. Настройка Supabase

1. **Создай таблицу** в Supabase:
   - Открой Supabase Dashboard
   - Перейди в SQL Editor
   - Скопируй и запусти содержимое файла `recipe_book_schema.sql`

2. **Получи ключи доступа**:
   - Перейди в Settings → API
   - Скопируй:
     - **Project URL** (Project API URL)
     - **Anon Public Key**

### 2. Настройка проекта

1. **Обнови `js/config.js`**:
   ```javascript
   export const SUPABASE_CONFIG = {
     URL: 'https://YOUR_PROJECT_ID.supabase.co',  // Замени на свой Project URL
     ANON_KEY: 'YOUR_ANON_KEY'                    // Замени на свой Anon Key
   };
   ```

2. **Структура файлов** (создай на GitHub):
   ```
   recipe-book-site/
   ├── index.html
   ├── book.html
   ├── admin.html
   ├── js/
   │   ├── config.js
   │   └── db.js
   └── README.md
   ```

### 3. Загрузка на GitHub Pages

1. **Создай репозиторий** на GitHub с названием `recipe-book-site`
2. **Загрузи файлы** в репозиторий
3. **Включи GitHub Pages**:
   - Settings → Pages
   - Source: Deploy from a branch
   - Branch: main (или master)
   - Folder: / (root)

4. **Твой сайт будет доступен** по адресу:
   ```
   https://твой-username.github.io/recipe-book-site/
   ```

## 📖 Использование

### Главная страница (`index.html`)
- Информация о сайте
- Ссылки на админ-панель и книгу

### Админ-панель (`admin.html`)
- **Пароль**: `addnew`
- **Добавить рецепт**:
  - Заполни форму
  - Выбери категорию, время, сложность, остроту
  - Добавь ингредиенты и шаги
  - Нажми "Сохранить"
  
- **Просмотр рецептов**:
  - Фильтруй по категориям
  - Ищи по названию
  - Редактируй или удаляй рецепты

### Книга рецептов (`book.html`)
- Просмотр всех рецептов в формате красивой книги
- Навигация: кнопки или стрелки ← →
- Автоматическое оглавление по категориям
- Красивое оформление с пастельными цветами по категориям

## 📋 Структура рецепта

Каждый рецепт содержит:
- **Название** — название блюда
- **Категория** — тип блюда
- **Время приготовления** — в минутах
- **Сложность** — ★☆☆, ★★☆ или ★★★
- **Острота** — от 0 до 3 (показывается огнём 🔥)
- **Ингредиенты** — список ингредиентов
- **Шаги** — пошаговое описание
- **Доп. информация** — советы, варианты, подсказки
- **Фото** — URL на изображение
- **Люимый** — отмечается сердечком 💚

## 🔐 Безопасность

- Админ-панель защищена простым паролем (`addnew`)
- Пароль хранится только в памяти браузера (сессия)
- Все данные хранятся в защищённой БД Supabase

## 🐛 Возможные проблемы

### Ошибка "не удаётся подключиться к БД"
- Проверь что ты добавил правильные ключи в `config.js`
- Убедись что Project URL и Anon Key скопированы верно
- Проверь что таблица `recipes` создана в Supabase

### Админ-панель просит пароль каждый раз
- Это нормально! Пароль хранится в памяти сеанса браузера
- Просто введи `addnew` снова

### Рецепты не появляются в книге
- Подожди несколько секунд загрузки
- Проверь что рецепты действительно сохранились в админ-панели
- Попробуй обновить страницу (F5)
